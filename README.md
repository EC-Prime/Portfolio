# Emmanuel Chuma — Developer Portfolio

A responsive portfolio website showcasing Emmanuel Chuma's background, development skills, featured projects, certification, and contact information. The site uses a football-inspired visual theme with interactive canvas effects and project demo videos.

## Live Website

[https://ec-prime.github.io/Portfolio/](https://ec-prime.github.io/Portfolio/)

## Technologies

- **HTML5** for page structure and content
- **CSS3** for styling, responsive layouts, and animations
- **JavaScript** for canvas effects, pointer interactions, scroll reveals, and lazy-loaded project videos
- **Canvas API** for the animated ASCII-style hero, ambient rain, and golden image traces
- **Boxicons** for interface icons
- **Devicon** for technology logos
- **Google Fonts** for DM Mono and Inter typography

## Features

- Responsive navigation and layouts for desktop, tablet, and mobile screens
- Animated hero section with an interactive ASCII-style canvas logo
- Ambient animated rain and golden footballer image traces
- About section, technical skills, and certification details
- Featured project cards with demo videos that load when needed
- Scroll-triggered reveal animations and reduced-motion support
- Contact form and direct email, GitHub, and LinkedIn links

## Run Locally

This is a static website and does not require a package manager, build step, or local server.

1. Clone the repository:

   ```bash
   git clone https://github.com/EC-Prime/Portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd Portfolio
   ```

3. Open `index.html` in a web browser. You can double-click the file or use a local development server if preferred.
